Built for the diffs you actually read

Every non-whitespace change, categorized and easy to act on.

Side-by-side and unified

Aligned A/B panes with character-level highlights, or a compact unified view. Switch instantly, no re-scan.

Whole-folder compare

Differing, only-in-A, only-in-B, whitespace-only, binary and identical files, each one click to filter. Make A or B match when you are ready.

Expand hidden gaps

Long unchanged stretches fold into a marker. Click to reveal the lines in place and click again to fold them back.

Precise selection and copy

Drag across lines within one side and copy exactly what you selected, including each line's own CRLF or LF when you select the newline.

Line-ending highlighting

Turn on whitespace-aware mode to see CRLF vs LF, tabs and spaces as visible marks, with changed line endings highlighted.

Local, full disk access, no cloud

Point it at any two folders on your PC or network. Nothing is uploaded: the comparison engine runs privately on 127.0.0.1.

Version 1.0 · Windows 10/11 x64

Heads-up: "Unknown publisher"

The installer is not code-signed yet, so Windows shows Unknown publisher and SmartScreen may say "Windows protected your PC". Choose More info → Run anyway, then Install.

Prerequisites installed separately, only once

The Socha Diff download itself is small (about 6 MB, measured from the published app) because it does not carry these three runtimes. Install each one once, and every Socha Diff update after that stays small. If you already have them, skip straight to Install.

a

.NET 10 Desktop Runtime (x64)

Microsoft · installer about 60 MB

Why: Socha Diff's window is a .NET 10 WPF app. Without the runtime, Windows shows ".NET is required to run this application" with a download link.

Check what you have
dotnet --list-runtimes
In PowerShell or cmd. Look for Microsoft.WindowsDesktop.App 10.0.x; "not recognized" means .NET is not installed.
Get it from dotnet.microsoft.com Pick .NET Desktop Runtime 10.0 → Windows → x64 installer.
b

Microsoft Edge WebView2 Runtime

Microsoft · usually already on Windows 10/11 · bootstrapper about 2 MB

Why: Socha Diff draws its interface with WebView2, the Edge engine for apps. It ships with Windows 11 and most up-to-date Windows 10 PCs.

Check what you have Settings → Apps → Installed apps, search for Microsoft Edge WebView2 Runtime. Or in PowerShell:
Get-ItemProperty 'HKLM:\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}' pv
Get it from developer.microsoft.com Choose Evergreen Bootstrapper; it downloads the right runtime (about 200 MB installed).
c

Node.js 20 or newer (LTS)

OpenJS Foundation · Windows Installer about 33 MB

Why: the comparison engine is a small Node.js server that Socha Diff starts privately on 127.0.0.1. It finds Node on PATH, in Program Files, or via nvm, fnm or Volta.

Check what you have
node --version
You need v20.0.0 or newer. The current LTS (v24) is recommended.
Get it from nodejs.org Pick the LTS Windows Installer (.msi). It adds Node to PATH.

System requirements

Operating system
Windows 10 (version 1607 or later) or Windows 11, 64-bit (x64)
Runtimes
.NET 10 Desktop Runtime x64, WebView2 Runtime, Node.js 20+ (details)
Disk
About 15 MB for Socha Diff, plus the prerequisites if they are not installed yet
Permissions
Installs per user, no administrator rights needed for the app itself
Network
Only to install and to check for updates at startup. Comparisons never leave your PC.

Good to know

  • Updates are automatic: every launch checks this site and installs a newer version before starting.
  • Settings and logs live in %LOCALAPPDATA%\SochaDiff and survive updates.
  • Uninstall from Settings → Apps → Installed apps → Socha Diff.
  • Mac or Linux? The same app runs in any browser from source: npm install, then npm start.
