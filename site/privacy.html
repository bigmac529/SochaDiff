Privacy

Socha Diff privacy policy

Short version: Socha Diff does not collect, store or send any personal data. Your folders and files never leave your PC.

What the app collects

  • Nothing. Socha Diff has no accounts, no analytics, no telemetry, no advertising and no crash reporting service.
  • Comparisons run locally. The app's built-in server listens only on your own PC (127.0.0.1) and is not reachable from the network. File names and contents are never uploaded anywhere.
  • The app only reads the folders you enter, and only changes files when you click Make A match B / Make B match A and confirm.

What stays on your PC

  • Your settings, the last two folders you compared and log files are saved in %LOCALAPPDATA%\SochaDiff on your PC (for the Microsoft Store version, Windows may keep them in the app's private storage instead). They are never sent anywhere. Uninstalling the Microsoft Store version removes its private storage; you can delete the folder at any time.
  • The window uses the Microsoft Edge WebView2 component, which keeps its own browser profile in the same folder. WebView2 is part of Windows and follows your Windows and Microsoft Edge diagnostic data settings; Socha Diff does not add anything to it.

When the app uses the network

  • Updates. The version installed from this website checks sochadiff.socha3.com for a newer version when it starts. The Microsoft Store version is updated by the Microsoft Store.
  • Links you click. The ? help button and links such as Get Node.js open in your default web browser.
  • Like any website, this site's web server and its CDN (Cloudflare) may keep standard access logs (IP address, time, requested file, browser) for security and operations. They are not used to identify you and are not sold or shared for advertising. The site sets no tracking cookies and uses no analytics.

Children

Socha Diff does not knowingly collect information from anyone, including children.

Changes and contact

If this ever changes, this page will be updated before a version that behaves differently is released. Questions: socha3.com.
